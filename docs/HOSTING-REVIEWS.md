# Отзывы на Unix shared-хостинге (CloudLinux / cPanel)

Сайт — статика (Vite `dist`), отзывы — **PHP + MySQL**. Это самый совместимый вариант для вашего тарифа (~1.5 GB RAM, 25 EP, 3 GB диск).

## Почему не Node на shared

Node на таком хостинге часто недоступен или убивается LVE. PHP + MySQL есть почти везде, фото лежат на диске, модерация через простой admin.

## Что уже в репозитории

- `api/reviews.php` — список одобренных + приём отзыва с фото
- `api/admin.php` — модерация (одобрить / отклонить)
- `api/schema.sql` + `api/seed.sql` — таблица и примеры
- `api/uploads/reviews/` — фото (скрипты запрещены `.htaccess`)
- Фронт: блок «Отзывы» с примерами + формой

## Деплой

1. В панели хостинга создайте MySQL БД и пользователя.
2. Импортируйте `api/schema.sql` (и по желанию `api/seed.sql`).
3. Скопируйте `api/config.example.php` → `api/config.php`, пропишите доступ к БД и пароль админа.
4. Соберите фронт с base `/` (не GitHub Pages):

```bash
# без GITHUB_ACTIONS — base будет /
npm run build
```

5. Залейте содержимое `dist/` в `public_html` (или корень сайта).
6. Залейте папку `api/` рядом: `public_html/api/`.
7. Права на запись: `api/uploads/reviews/` → `755` или `775` (чтобы PHP мог сохранять фото).
8. Если в seed есть примеры — убедитесь, что лежат файлы в `api/uploads/reviews/examples/`.

## Модерация

Откройте: `https://ваш-домен/api/admin.php`  
Введите пароль из `config.php` → `admin_password`.

Новые отзывы со статусом `pending` не видны на сайте, пока не нажмёте «Одобрить».

## Лимиты под ваш хостинг

| Ограничение | Как учтено |
|---|---|
| Диск 3 GB | Фото сжимаются в браузере + на сервере до ~1280px JPEG |
| EP 25 / CPU 150% | Лёгкий PHP, без Node; лимит 3 отзыва / IP / сутки |
| RAM 1.5 GB | Нет тяжёлых демонов, только PHP-FPM/CGI по запросу |
| Трафик | WebP/JPEG, lazy-load на фронте |

## Локальная разработка

Без PHP форма покажет ошибку при отправке, а сетка — статические примеры из `src/content/reviewExamples.ts`.

Для проверки API нужен PHP+MySQL (OpenServer / XAMPP / Docker) с корневой папкой, где доступны `/api` и собранный фронт.
